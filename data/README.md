# Data

The raw data is not stored in this repository (1.28 GB, over GitHub's file limit).

**Source:** Kaggle, "SPY Option Chains Q1 2020 – Q4 2022" (end-of-day SPY option chains).

**Setup:** download the dataset from Kaggle, unzip it, and place the file here:

```
data/raw/spy_2020_2022.csv
```

Expected: 3,589,079 rows, 33 columns, quote dates 2020-01-02 to 2022-12-30 (758 dates).

## Known issues

- **Holiday snapshots:** 9 quote dates in 2022 fall on NYSE holidays (2022-01-17, 02-21, 04-15,
  05-30, 06-20, 07-04, 09-05, 11-24, 12-26). They are near-copies of the previous session and
  are dropped during cleaning, leaving 749 trading days.
- **Missing trading days:** 2020-06-18, 2020-11-27, 2020-12-24, 2022-05-11, 2022-06-17,
  2022-06-24, 2022-12-16.

`data/processed/` holds files generated by the cleaning scripts; it is also not committed.
